# QAICYS 2026 – Event Website

A responsive event website developed for QAICYS 2026, an intra-collegiate techno-cultural confluence at Manikam Ramaswami College of Arts & Science (MRCAS).

## Key Features
- Immersive dark-themed user interface
- Event logo and tagline integration
- Event overview and dedicated event sections
- Interactive event category browsing
- Registration access
- Python-based backend
- Responsive and user-friendly design

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (Django)
- **Configuration & Deployment:** Docker, Docker Compose, Vercel

## My Role
As Student Coordinator and website developer, I contributed to building a professional digital platform, designing the user interface, organizing event information, and presenting event categories and registration access.
