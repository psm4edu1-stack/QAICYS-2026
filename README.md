# QAICYS 2026 – Event Website

A responsive website developed for QAICYS 2026, an intra-collegiate techno-cultural confluence at Manikam Ramaswami College of Arts & Science (MRCAS).

## Features
- Immersive dark-themed user interface
- Event branding with logo and tagline
- Event overview and dedicated event sections
- Interactive event category browsing
- Registration access
- Responsive and user-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## My Role
As Student Coordinator and website developer, I contributed to creating a professional digital platform, organizing event information, implementing the interface, and improving access to event details and registration.

College Event Website
